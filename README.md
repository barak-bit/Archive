# ארכיב

ארכיון ציבורי קבוע על הבלוקצ'יין של ביטקוין. מסמך שנרשם כאן כתוב בתוך עסקת ביטקוין, ונשאר קריא לכל אחד גם אם האתר הזה ייסגר.

האתר מורכב משני חלקים:

1. **האפליקציה** (`index.html`): רישום מסמך, ארכיון עם חיפוש ואימות מסמך. הכול רץ בדפדפן של המשתמש. המשתמש משלם מהארנק שלו, והאתר לא מחזיק כסף או מפתחות.
2. **דפי הפרסום** (`p/`): דף קבוע לכל פרסום, עם תאריך, תקציר, טביעת אצבע והוראות אימות. הדפים נבנים מחדש מהבלוקצ'יין כל 6 שעות, כך שגוגל ובוחני פטנטים יכולים למצוא אותם.

אין שרת ואין מסד נתונים. אם כל האתר יימחק, אפשר לבנות אותו מחדש מהבלוקצ'יין.

---

## העלאה ל-GitHub, צעד אחר צעד

**1. פותחים מאגר (repository)**
- נכנסים ל-github.com, נרשמים או מתחברים.
- לוחצים על **+** למעלה ← **New repository**.
- שם: `archiv`. מסמנים **Public** (אתר GitHub Pages חינמי דורש מאגר ציבורי). **לא** מסמנים "Add a README".
- לוחצים **Create repository**.

**2. מעלים את הקבצים**
- במסך שנפתח לוחצים על הקישור **uploading an existing file**.
- גוררים לחלון את כל הקבצים מהתיקייה `archiv`. כולם קבצים רגילים, בלי תיקיות.
- למטה לוחצים **Commit changes**.

**2א. יוצרים את קובץ הבנייה**
את הקובץ הזה צריך ליצור ישירות באתר, כי הוא חייב לשבת בתיקייה `.github/workflows`.
- במאגר: **Add file** ← **Create new file**.
- בשדה שם הקובץ מקלידים בדיוק: `.github/workflows/pages.yml` (כל `/` יוצר תיקייה).
- פותחים את הקובץ `pages.yml` מהתיקייה במחשב בפנקס רשימות, מעתיקים את כל התוכן ומדביקים בחלון העריכה.
- **Commit changes**.

**3. מפעילים את GitHub Pages**
- במאגר: **Settings** ← בתפריט הצד **Pages**.
- תחת **Build and deployment** ← **Source** בוחרים **GitHub Actions**.

**4. מריצים את הבנייה**
- לשונית **Actions** ← **Build and publish** ← **Run workflow**.
- אחרי 1–3 דקות מופיע וי ירוק. הבנייה מריצה קודם את כל הבדיקות, ומפרסמת רק אם הן עברו.
- האתר זמין בכתובת `https://<שם-המשתמש>.github.io/archiv/`. הכתובת מופיעה גם ב-Settings ← Pages.

מכאן כל שינוי שתעלו לקבצים בונה את האתר מחדש. מעבר לזה, הוא נבנה מחדש לבד כל 6 שעות כדי להוסיף פרסומים חדשים.

**אם הבנייה נכשלת:** לוחצים על הריצה האדומה בלשונית Actions ← על השלב האדום, ומעתיקים את הודעת השגיאה.

## הדגמה

האתר מחובר לרשת הבדיקה של ביטקוין (testnet4), שבה המטבעות חסרי ערך. כדי להראות אותו עובד:
1. מתקינים ארנק שתומך ב-testnet4 ומקבלים בו מטבעות בדיקה בחינם מ-faucet (מחפשים "testnet4 faucet").
2. באתר רושמים מסמך קצר, עם כותרת ותקציר, ומשלמים מהארנק לכתובת התשלום.
3. אחרי שהעסקה נכנסת לבלוק, המסמך מופיע בלשונית "הארכיון" באתר.
4. דף הפרסום הקבוע שלו (`/p/`) נוצר בבנייה הבאה. כדי לא לחכות 6 שעות: Actions ← Run workflow.

## הגדרות: `config.json`

| שדה | מה הוא קובע |
| --- | --- |
| `network` | `testnet4` לבדיקות, `mainnet` לרשת האמיתית |
| `siteName` | שם האתר בדפי הפרסום |
| `siteUrl` | כתובת האתר. ב-GitHub Pages היא נקבעת אוטומטית, ואפשר להשאיר ריק |
| `reportEmail` | כתובת לדיווח על תוכן פוגעני |
| `hiddenTxids` | מזהי עסקאות שיוסתרו מהאתר אחרי תלונה. הם נשארים בבלוקצ'יין |
| `publicPages` | האם להציג באפליקציה קישור לדף הפרסום הקבוע |
| `cardPayment` | תשלום בכרטיס אשראי דרך שירות כמו MoonPay. פעיל רק ב-mainnet ורק כשמוגדר `urlTemplate` |

**אסור לשנות** את `ARCHIVE_TAG` בקובץ `src/engine.js`. הוא קובע את כתובת הארכיון, ושינוי שלו אחרי הרישום הראשון יפצל את הארכיון לשתי כתובות.

## דומיין משלכם

Settings ← Pages ← **Custom domain**, ואצל רשם הדומיין מוסיפים רשומת DNS לפי ההוראות של GitHub. עם דומיין משלכם גם `robots.txt` ומפת האתר יעבדו כמו שצריך מול גוגל. בכתובת `github.io/archiv` גוגל לא קורא את `robots.txt`, ואת מפת האתר צריך להגיש ידנית ב-Google Search Console.

## למפתחים

```
engine.js           בניית העסקאות וחתימה (Ordinals, פיצול, דחיסה, שחזור)
app.html            האפליקציה
build.mjs           בונה את dist/index.html
build-index.mjs     בונה את dist/p/ מהבלוקצ'יין
*.test.mjs          בדיקות
mock-chain.mjs      API מדומה של ביטקוין, לבדיקות
pages.yml           עותק של קובץ הבנייה, ‎.github/workflows/pages.yml
```

```
npm install
npm test             # בדיקות המנוע, אימות קריפטוגרפי של חתימות, ובניית דפי הפרסום מול API מדומה
npm run build:app    # בונה רק את האפליקציה (לא צריך רשת)
npm run build        # האפליקציה ודפי הפרסום מהבלוקצ'יין האמיתי
```

ספריות: [@scure/btc-signer](https://github.com/paulmillr/scure-btc-signer), [micro-ordinals](https://github.com/paulmillr/micro-ordinals), [@noble/hashes](https://github.com/paulmillr/noble-hashes).

**אבטחה:** תוכן רשום הוא קלט לא מהימן. האפליקציה ודפי הפרסום פותחים רק סוגים שלא מריצים קוד (טקסט, PDF ותמונות רגילות). כל השאר מוצע להורדה בלבד ולא נשמר כקובץ באתר.

**לפני מעבר ל-mainnet:** בדיקות מלאות ב-testnet4, ביקורת קוד חיצונית וחוות דעת משפטית.
